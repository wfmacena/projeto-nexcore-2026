## Dicas gerais:

1. **Qualidade de imagem:** Sempre tire prints em tela cheia (Win + Shift + S no Windows).
2. **Nome dos arquivos:** Use os nomes exatos listados em cada `LEIA-ME.md` — isso evita confusão na correção.
3. **Não é necessário ter equipamento/VM real:** Mockups no PowerPoint, Canva ou prints de tutoriais do YouTube são aceitáveis desde que sejam coerentes.
4. **Quando preencher:** Você pode ir colocando as evidências aos poucos, não precisa de tudo de uma vez.
5. **Backup:** Após colocar os prints, faça commit no GitHub para não perder.
