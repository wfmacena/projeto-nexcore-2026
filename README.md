### 3. Redes de Computadores
- Plantas dos 3 locais (Matriz SP + Filiais Campinas e Ribeirao Preto)
- Topologia logica e fisica
- Cabeamento estruturado, Wi-Fi e VLANs
- Enderecamento IP por sub-rede
- **Projeto no Cisco Packet Tracer (OBRIGATORIO pelo professor): Matriz SP com 2+ VLANs, ping inter-VLAN funcional**

**Acessar:** [redes/](redes/)

---

### 4. Internet das Coisas (IoT)
- Problema: Monitoramento de temperatura na Sala de Servidores (CPD) da Matriz SP
- **Especificacao do professor:** Circuito no Tinkercad com Arduino, protoboard, **TMP36**, **LEDs** e **resistores**
- Sensor analogico TMP36 mede temperatura em graus Celsius
- LEDs de status: Verde (normal < 28C), Amarelo (alerta 28-35C), Vermelho (critico >= 35C piscando)
- Codigo-fonte C++ (.ino) desenvolvido pela equipe (sem bibliotecas externas, usa apenas analogRead())
- Projeto simulado no Tinkercad (5 prints obrigatorios: montagem + 3 testes + serial)

**Acessar:** [iot/](iot/)
